# Aagee Product Messaging

Note: The Aagee Brand Guidelines (2025) do not include a product messaging or copywriting section. This document should be created to cover: core value proposition, tagline, key messages by audience, and approved claims.

Until a formal product messaging document exists, the following is not available in the brand guidelines:
- Official tagline
- Approved product claims
- Channel-specific messaging

If you need to create product copy, refer to the visual brand positioning in brand-book.md: Aagee is modern, fast-moving, forward-thinking, and technology-focused. The design language is bold and high-contrast — copy should match this directness.
