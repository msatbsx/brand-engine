# Aagee Colour System

## Palette

| Name | Hex | Role |
|------|-----|------|
| Lime | #DDFB66 | Primary brand colour — the main focus colour |
| Mint | #9CEE95 | Supporting accent — freshness |
| Sky | #83C6ED | Supporting accent — visual engagement |
| White | #FFFFFF | Neutral background |
| Black | #111111 | Neutral — text and background |
| Dark Grey | #1A1A1A | Neutral — background |
| Midnight Navy | #131F30 | Neutral — dark background |

Lime is the focus. Mint and Sky are accents. Neutrals are for backgrounds and text.

## Suggested Colour Schemes

High-contrast combinations recommended for legibility:

- Dark Grey + Lime (background + accent)
- Midnight Navy + Lime
- Lime + Midnight Navy (reversed)
- Dark Grey + Mint
- Mint + Dark Grey (reversed)
- Dark Grey + Sky
- Sky + Dark Grey (reversed)

## Combinations to Avoid

Do not use colour combos that create legibility issues with text or graphic elements:

- Lime on White — fails contrast
- Mint on White — fails contrast
- Sky on White — fails contrast
- Dark Grey on Midnight Navy — too similar
- Mint on Lime — too similar
- Sky on Lime — too similar
- Sky on Mint — too similar
- Mint on Sky — too similar
- Black on Midnight Navy — fails contrast

## Colour Gradients

Gradients can be created using Lime, Mint, and Sky colours, applied at a 45° diagonal angle to create a soft and smooth transition.

Use gradients as background elements only. Always prioritise contrast and readability when layering text or graphic elements over a gradient.

Approved gradient directions: 45° angle only.
Approved gradient colours: Lime, Mint, Sky (separately, not combined).
